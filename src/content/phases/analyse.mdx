    title: Today

      - Your processes live as BPMN in your engines, in BPM suites such as Signavio, as Visio or draw.io diagrams, and in the heads of the people who run them

tools:
  - tool: analyzr
    text:
      - analyzr reads BPMN models from the sources below into one landscape. Code without an LLM extracts the facts, and agents in an MCP client you choose, such as Claude Code, propose how the processes connect and which value chain step each one belongs to. You get a reviewed as-is landscape in which every link and placement records where it came from and who decided it.
      - The [read-only demo](https://analyzr-demo.fly.dev/projects/nordwind-handel/review) shows two synthetic landscapes, worked by a simulation agent without an LLM.
    status: Early alpha (0.1.0-alpha.0) in a private repository, with no public release yet, local mode only, web UI and agent rationales in German.

human:
  - icon: cog
    title: The agents
    text: Propose links and placements with confidence and a rationale but cannot accept them. A rule without an LLM accepts unambiguous call activities.
  - icon: users
    title: Your team
    text: A person on your team decides every other proposal in review (accept, reject, hold or correct), unless an auto-accept rule that the project owner set covers it. There are none by default.
handover:
  - direction: in
    label: At the start
    text: Your existing models from the sources above, optionally with a value chain in the format of the public [Value Chain Modeler](https://github.com/Miragon/modeler-suite/tree/main/modelers/value-chain). If you re-upload a changed model later, it becomes a new revision, only models whose facts changed are analysed again, and earlier decisions stay valid unless an endpoint's meaning changed.
    formats:
      - BPMN 2.0 XML (.bpmn, .bpmn2, .bpmn20.xml)
      - .vc.json
  - direction: out
    label: To Design
    link: /design/
    text: The reviewed as-is landscape with the relations between processes, the placements on the value chain, findings such as unresolved calls or processes without a step, and the model revisions. analyzr has no direct connection to designIQ or bpmn-cli yet.
    formats:
      - REST (OpenAPI 3.1)
      - MCP read tools
      - .vc.json via analyzr value-chain pull
