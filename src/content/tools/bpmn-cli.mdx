<PageSection tone="tint" eyebrow="Findings" title="Each finding names the command that fixes it" intro="For the session at the top of this page, one bpmn set gives the service task an external topic, and the next check passes.">

```sh
bpmn set order.bpmn Activity_ReserveStock camunda:type=external camunda:topic=reserve-stock
bpmn validate order.bpmn --strict   # valid, 0 warning(s)
```
